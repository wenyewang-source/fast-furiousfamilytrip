# Fast & Furious Family Trip

Austin, November 13–17, 2026. Proposed itinerary; nothing booked.

## Cloudflare Pages

Connect this GitHub repository to Cloudflare Pages.
- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (repository root)

This is a static site. No database, environment variables or API keys are needed.
To Do, booking checks and expenses stay in each visitor’s own browser and do not sync.

Based on [Travel-Plan-Page](https://github.com/do-tongxue/Travel-Plan-Page), with an English interface and a custom Austin itinerary. See LICENSE.
